# 🕌 مُتابع العبادات اليومية
## Islamic Daily Worship Tracker

تطبيق Android شامل لمتابعة العبادات اليومية مبني بـ Flutter/Dart.

---

## 📋 المتطلبات

- Flutter SDK 3.10+
- Dart 3.0+
- Android Studio أو VS Code
- Android SDK 21+

## 🚀 طريقة التشغيل

### 1. إنشاء مشروع Flutter جديد
```bash
flutter create islamic_tracker
cd islamic_tracker
```

### 2. نسخ الملفات
انسخ جميع الملفات من هذا المجلد إلى مشروعك مع الحفاظ على نفس البنية.

### 3. إضافة الخطوط والأصوات
```bash
mkdir -p assets/fonts assets/sounds
```

- حمّل خط Amiri من: https://fonts.google.com/specimen/Amiri
- ضع ملفات .ttf في `assets/fonts/`

### 4. تثبيت الاعتماديات
```bash
flutter pub get
```

### 5. تشغيل التطبيق
```bash
# على جهاز Android
flutter run

# بناء APK للتوزيع
flutter build apk --release
# الملف سيكون في: build/app/outputs/flutter-apk/app-release.apk
```

## ✨ المميزات

### 🕌 الشاشة الرئيسية
- عرض تاريخ اليوم بالعربية
- عداد تنازلي للصلاة القادمة
- تتبع الصلوات الخمس مع مواقيتها الفعلية
- تسجيل الصوم / الزكاة / صلة الرحم
- شريط تقدم يومي

### ⚙️ القائمة العلوية اليمين (⋮)
- **الإعدادات** → تفعيل/تعطيل كل عبادة، ضبط الموقع
- **التقارير** → يومي / شهري / سنوي
- **الخروج**

### 🔔 الإشعارات
| الإشعار | التوقيت |
|---------|---------|
| 🕌 الصلاة بعد قليل | قبل كل صلاة بـ 10 دقائق |
| 🌙 لا تنسَ صوم الاثنين | الأحد 8 مساءً |
| 🌙 لا تنسَ صوم الخميس | الأربعاء 8 مساءً |
| 🤝 صلة الرحم | يومياً 8 صباحاً |
| 💰 الزكاة | أول يوم كل شهر |
| ⭐ مناسبات إسلامية | ليلة كل مناسبة |
| ⚪ أيام البيض | ليلة 13 كل شهر |

### 📋 الاستبيانات (بعد ساعة من كل صلاة)
- هل صليت في المسجد؟ (نعم/لا)
- هل ذكرت الله؟ (نعم/لا)
- هل أديت صلاة السنة؟ (نعم/لا)
- هل قرأت وردك من القرآن؟ (نعم/لا)

### 📊 التقارير
- **يومي**: حالة كل عبادة اليوم
- **شهري**: نسب الالتزام + رسم بياني للصلوات
- **سنوي**: إحصائيات سنوية كاملة
